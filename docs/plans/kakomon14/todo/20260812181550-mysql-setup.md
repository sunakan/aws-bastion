# MySQLのセットアップ(40-mysql.sh)

## 目的

Ansibleの`roles/mysql`相当を再現する。`0-init.sql`は誰も実行しないため、mysql roleのGRANT処理だけで足りることが分かっている。

## やること

- `mysql-server`をaptインストールし、有効化・起動する
- `isucon`ユーザーを作成し(`CREATE USER IF NOT EXISTS` + `ALTER USER`でパスワードを確定させる)、`GRANT ALL PRIVILEGES ON *.* TO 'isucon'@'%' WITH GRANT OPTION`を実行する
- DBユーザー名/パスワードは`isucon`/`isucon`のまま据え置く(webapp/go・init.shの既定値と一致させ、パッチを避けるため)

## 完了条件

`mysql -uisucon -pisucon -e 'select 1'` が成功すること
