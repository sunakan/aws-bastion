# frontendビルド(80-frontend.sh)

## 目的

nginxのrootが指す`webapp/public/`を用意する。公式は`make_latest_files.sh`でtar.gzに同梱しているが、`webapp/public`はisucon14の`.gitignore`に入っているため、cloneしたツリー内でビルドしてもツリーは汚れない。

## やること(重要な順序制約あり)

- isurenユーザーでNode/pnpmを使い、`frontend`ディレクトリで`pnpm install --frozen-lockfile && pnpm run build`を実行する
- ビルド成果物(`build/client/`)を`webapp/public/`にコピーする
- **frontendのビルドは、bench側のビルド/実行より必ず先に行う**。`frontend/vite.config.ts`のプラグインがビルド時に`bench/benchrun/frontend_hashes.json`を再生成するため、順序を守らないとベンチの負荷走行中に静的ファイルのMD5検証が全て失敗する(`--skip-static-sanity-check`はPrepare時のみ有効でこの検証は止められない)

## 完了条件

`frontend_hashes.json`に記載された各ファイルのmd5と、`webapp/public/`配下の実ファイルのmd5が全て一致すること
