# nginx HTTP版(90-nginx.sh) 【マイルストーンC】

## 目的

まず証明書なしで全経路(静的配信+`/api/`プロキシ)を通す。公式の本番vhostはHTTPS(443)のみでアプリに繋がる構成だが、TLSは後回しにして最速で動作確認できる状態を先に作る。

## やること

- nginxをaptインストールする
- HTTP専用vhost(`listen 80`、静的ファイルは`webapp/public/`から配信、`location /api/`は`http://localhost:8080`にプロキシ)を配置する
- デフォルトの`sites-enabled/default`を削除する
- `nginx -t`で検証してから`reload`する

## 完了条件

- `go run . run --target http://localhost -t 60` (`-s`なし)が成功すること
- ブラウザで`http://<bastion-public-ip>/client`が開くこと

## 決定事項

- 公式のボット避けデフォルトvhost(自己署名証明書での80/443キャッチオール)は本番運営向けのセキュリティ対策でありこのbastionでは不要と判断し、単一のHTTP vhostのみに簡略化した
- `scripts/kakomon14/90-nginx.sh`をbastion上で2回実行し、1回目changed→2回目already up to dateを確認済み。`nginx -t`の構文チェックも成功
- `go run . run --target http://localhost -t 60`(`-s`なし、静的ファイル検証込み)で`pass=true`・スコア=1201を確認済み。CODE=25のタイムアウトエラーが1件出たが、AGENTS.mdに記載のあるインスタンスのリソース不足由来の既知事象であり、静的ファイル検証の失敗ではない
- `curl http://localhost/client`でHTTP 200・正しいHTML(Remixアプリのマウントポイント)が返ることを確認済み(完了条件を満たす)
