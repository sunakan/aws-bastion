# OS基本設定(10-base.sh)

## 目的

Ansibleの`roles/base`相当のOSチューニングを、冪等なbashスクリプトとして再現する。

## やること

- タイムゾーンをUTCに設定する
- `/etc/sysctl.d/99-isuren.conf`で`net.ipv4.ip_local_port_range`を`10000 65535`に設定する
- `/etc/security/limits.d/99-isuren.conf`でnofile/nproc上限、memlock unlimitedを設定する
- `/etc/hosts`に`127.0.0.1 isuride.xiv.isucon.net`を追加する(matcherはlocalhost直叩きにするため必須ではないが、ブラウザ確認用に残す)

## 完了条件

スクリプトを2回実行して、2回目に差分(changed)が出ないこと

## 決定事項

- ホスト名は`isuride.xiv.isucon.net`ではなく`isuride.xiv.isuren.internal`を使う。`.internal`はICANNが私設ネットワーク専用に予約したTLD(2024年7月)で、`.local`と違いmDNS(RFC 6762)の特殊扱いを受けない。`webapp/go`・`frontend`にisucon.net依存箇所がなく、benchも手動`--target`実行時は無関係(supervisor経由起動時のみ有効な分岐)のため置き換えても実害なしと確認済み
- `/etc/ssh/sshd_config.d/pubkey.conf`(`PubkeyAcceptedAlgorithms=+ssh-rsa`)は意図的に未対応。旧SSHクライアント互換のための設定で、bastionからの接続は最新クライアント前提のため不要と判断
- `scripts/kakomon14/10-base.sh`をbastion上で2回実行し、1回目全項目changed→2回目全項目already-up-to-dateを確認済み(完了条件を満たす)
