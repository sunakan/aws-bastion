# isuren版の環境セルフチェックがあると良いかも

## きっかけ

isucon14本家の`envcheck/`(`isucon-env-checker`)を調査した際に見つけたアイデア。
本家のものはISUCON運営のポータル認証・本番競技クラスタ(3台構成、`c5.large`、EBS 20GB、
特定のインスタンス名)に強く依存しており、isurenの自前ホスティング環境ではそのままでは動かない
(EC2 Describe権限を持つIAMロールも今はアタッチしていない)ため、vendor対象からは除外した。

## メモ

「環境が期待通りか自己診断する」という発想自体は、isuren向けに作り直せば有用かもしれない。
例えばインスタンスタイプ・EBSサイズ・AMI IDが想定通りか、IMDS経由でインスタンス自身が
チェックする、といった軽量な仕組み。

今は不要。優先度が上がったら`docs/plans/kakomon14/todo/`に起票する。
